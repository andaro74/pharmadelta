pharmadelta · front page

pharmadelta is an independent open-source demo and is not affiliated with any pharmaceutical company. The company, Ardentia Generics, is fictional; its portfolio and every “our label” statement are invented. The labels are real public-domain labels of old off-patent generics, read from DailyMed.

A labeling rule changed. Which of our labels does it touch, and what do we owe?

That is the one question this demo answers. Every answer cites one row of a label table and one clause of FDA regulation (21 CFR Parts 201 and 314). The agent that answers, label-impact, is a tenant of the agentkeel platform. This site holds what surrounds it: the pages, the data they copy, and the ledger that says what was claimed and what was measured.

What these pages are. Each page shows a record of a call that this repository's CI made and saved, with the run that made it linked. Nothing here calls the agent when you open a page, and there is no box to type a question into. Where the agent gave no answer, the page says so and shows what the call returned. Where the baseline is shown, it is a deliberately weak control, not an assistant anyone would ship.

The pages

Detail One question sent to the deployed agent. The agent's answer with its row and its clause, or "No row found" with what the call returned, and the record of the call.
Side by side The same question answered by an ordinary assistant (the frozen keyword baseline, run by CI) and by the deployed agent, next to each other.
Try to break it Two attack questions sent through the agent's door: a request for dosing advice and an instruction hidden in a pasted document. What the platform's guardrail did on each, with the rule it fired.
Sign-off A seat holder's signature over a downloadable evidence package: the CI results the ledger cites, the ledger, the spec, the goldens and the served files, each with its hash and its source linked.

The record

The ledger One row per milestone: the claim, the commit that made it false, the gate that caught it, and the CI run that measured it. Rows that stayed RED say so.
SPEC/00 The authority for what this demo claims. If a page and the spec disagree, the spec wins.
The evidence package pages/evidence/m06-evidence.zip. Its SHA-256 and its contents are listed on the sign-off page; the build that wrote it is linked there.
The repository The code, the data, the goldens and the workflows. This site is the main branch served as it is.

The data behind the pages

Each page copies one JSON file, served beside it: answers.json, baseline.json, break-it.json and sign-off.json. A reader who distrusts a page reads the file.

pharmadelta answers no treatment question; it assesses regulatory impact on labeling, nothing else. Citations are checked against the eCFR before they appear (SPEC/00 P7). This page is navigation; it copies no number and shows no answer.
