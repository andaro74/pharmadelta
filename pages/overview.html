pharmadelta is an independent open-source demo and is not affiliated with any pharmaceutical company. The company, Ardentia Generics, is fictional; its portfolio and every “our label” statement are invented. The labels are real public-domain labels of old off-patent generics, read from DailyMed.

A labeling rule changed. Which of our labels does it touch, and what do we owe?

A generics company holds many drug labels, and FDA labeling rules change. Each time, someone has to work out which labels the change touches, what the company owes because of it, and which rule says so. pharmadelta is a demo of an agent that answers that one question, and of what has to surround the agent before anyone can rely on the answer.

What this page is. An overview in three pictures, written by hand. It measures nothing and shows no result of its own. The one answer drawn below is the saved record of a call this repository's CI made; the side-by-side page shows that record in full, with the run that wrote it. What was measured is in the ledger.

1. One rule change, start to finish

The question below is a trap. It asks about an earlier version of a rule. An assistant that matches keywords sees “pregnancy”, “category letter” and the label's name, and says the label must change. The agent looks up the label's row, cites the clause, and answers that nothing is owed.

The three traps on the pages

A rule no longer in force The question quotes an earlier version of a rule. What the earlier version asked for is not owed.
A route not open to us on our own The question names a real filing route, for a change the reference drug's label does not carry. A generics company keeps its label the same as the reference drug's.
A reportable event inside a note about something else A distributor's note about a carton shortfall mentions, in one sentence, a patient admitted to hospital. The label does not change. A report is owed.

Each trap, with the row and the clause behind each answer and the answer the test expects, is on the side-by-side page.

2. The same job, two ways

Illustration. The left lane of this picture was written by hand to show where a manual process leaves questions open. Nobody measured a manual process for this demo: it claims no time, no cost and no error rate (SPEC/00 P8).

3. Who owns what

The agent runs on a platform that gives every agent seven seats. Each seat is a named person who decides one thing. The platform refused this agent while one seat was empty (ledger row 1).
