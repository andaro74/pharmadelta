pharmadelta · side-by-side page

pharmadelta is an independent open-source demo and is not affiliated with any pharmaceutical company. The company, Ardentia Generics, is fictional; its portfolio and every “our label” statement are invented. The label is a real public-domain label of an old off-patent generic, read from DailyMed.

This page shows the same question answered by an ordinary assistant and by the deployed agent (SPEC/00 §1). The ordinary assistant is this repository's frozen baseline, src/baseline/: a keyword matcher over the question, the label table and the clauses, with no model, frozen at tag m00 and never improved (SPEC/00 P5). It is the control the agent is compared with, not an assistant anyone would ship. The agent is label-impact, a tenant of agentkeel, called through its door as the caller pharmadelta. The left column copies api/baseline.json; the right column copies api/answers.json, the same entry the detail page detail.html shows.
